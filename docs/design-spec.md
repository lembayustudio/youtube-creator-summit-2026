# Design Specification

This document defines the overall visual design system used throughout the Event Landing Page Starter Kit.

---

# Design Principles

- Modern
- Minimal
- Premium
- Professional
- Responsive
- Accessibility First

---

# Shadows

Prefer soft shadows.

Avoid harsh black shadows.

---

# Animation

Use subtle motion only.

Duration:

200ms–350ms

Easing:

ease-out

Hover:

- Slight lift
- Slight scale
- Glow

Avoid excessive animation.

# Responsive Breakpoints

Mobile

Tablet

Desktop

Large Desktop

---

# Accessibility

Minimum contrast ratio

4.5:1

Always provide:

- alt text
- semantic HTML
- keyboard navigation
- visible focus states
